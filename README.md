# 棚卸照合ツール（預り書 × SAP在庫残データ）

預り書の Excel と SAP から出力した在庫残の Excel を読み込み、**倉庫 × 型式**の単位で
数量を集計して突き合わせ、差異を CSV に出力するツールです。

出力対象は**預り書の倉庫名に紐づくものだけ**です。SAP 側にしか無い倉庫
（取引先名など、自社の棚卸対象外の保管場所）は結果に含めません。

**インストール作業は一切不要です。** `棚卸照合ツール.html` をダブルクリックすると
Windows 標準のブラウザ（Microsoft Edge）で画面が開きます。

---

## 使い方

1. **`棚卸照合ツール.html` をダブルクリック**する
2. 3つの Excel をドラッグ＆ドロップ（または枠をクリックして選択）
   | | ファイル | 使用する列 |
   |---|---|---|
   | ① | 預り書 Excel | **A列** 倉庫名 / **E列** 型式 / **I列** 台数 |
   | ② | SAP在庫残データ Excel | **E列** 保管場所名 / **G列** 品目テキスト / **J列** 基本数量 |
   | ③ | 保管場所 変換表 | **A列** 変換前 / **B列** 変換後 |
3. 画面に出る**プレビュー**で、列とデータ開始行が合っているか確認する
   （シートとデータ開始行はファイルごとに変更できます。既定は「先頭シート・2行目から」）
4. **「棚卸照合を実行」** を押す
5. 画面で差異を確認し、**「全件CSV」** または **「差異のみCSV」** を保存する

ファイルはお使いの PC のブラウザ内だけで処理されます。ネットワークに送信されることはありません。

---

## 照合のしくみ

1. **変換表で SAP の保管場所名を倉庫名に変換する**
   変換表（A列→B列）に無い保管場所名は、**元の名前のまま**使用します。
2. **同じ 倉庫 × 型式 の明細を合計する（サマる）**
   同じ倉庫・同じ型式が複数行に分かれていても、合計してから比較します。
3. **預り書に存在する倉庫だけに絞る**
   SAP 側にしか無い倉庫の在庫は棚卸の対象外なので結果に含めません。
   除外した倉庫は件数・数量つきで画面の「確認事項」に一覧表示されるので、
   倉庫名の書き間違いで消えていないか確認できます。
4. **預り書と SAP を突き合わせる**
   （絞り込んだうえで）片方にしか無いキーも結果に含めます。

### 判定区分

| 判定 | 意味 | 疑われること |
|---|---|---|
| **一致** | 両方にあり数量も同じ | — |
| **差異** | 両方にあるが数量が違う | 数え間違い・入出庫の未計上 |
| **預り書のみ** | 預り書にあるが SAP に無い | SAP への登録漏れ |
| **SAPのみ** | SAP にあるが預り書に無い | 現物の紛失・棚卸の計上漏れ |

### 突合ルール

- 倉庫名・型式は **完全一致**で突合します。前後の空白や全角/半角の違いは
  別のものとして扱われます。
  そのため、**空白や全角半角だけが違う「惜しいキー」**は、結果を変えずに
  画面の「確認事項」に一覧表示して原因調査ができるようにしています。
- 数量は数値セルのほか、`1,234`（桁区切り）、`１２３`（全角）、`(123)` / `△123` / `123-`
  （負数）も解釈します。解釈できない値（`12台` など）は 0 として集計し、確認事項に出します。
- 倉庫名または型式が空の行は集計対象外にします（ただし倉庫名そのものは
  「預り書に存在する倉庫」として扱います）。件数は確認事項に出します。
- 小数の丸め誤差（`0.1 + 0.2` など）は一致として扱います。

## 出力される CSV

- **UTF-8（BOM 付き）・CRLF** なので、Excel でダブルクリックしても文字化けしません。
- 列構成

  | 判定 | 倉庫名 | 型式 | 預り書台数 | SAP基本数量 | 差異(預り書-SAP) | 預り書明細件数 | SAP明細件数 | SAP保管場所名(変換前) |
  |---|---|---|---|---|---|---|---|---|

- 並び順は「預り書のみ → SAPのみ → 差異 → 一致」。差異が上に来ます。
- `預り書明細件数` / `SAP明細件数` は、そのキーを何行分サマったかです。1 より大きければ
  複数明細を合計した結果だと分かります。
- `SAP保管場所名(変換前)` には変換前の名称が入るので、変換表が効いているか追跡できます。

### ファイル名について

「名前を付けて保存」ダイアログが使えるブラウザ（Edge / Chrome）では、
`棚卸照合結果_20260731_1200.csv` のような日本語のファイル名を提案します。

ダイアログが使えないブラウザでは、ダウンロードフォルダに
`tanaoroshi_result_20260731_1200.csv` という **ASCII のファイル名**で保存されます。
これは、ブラウザによっては日本語のファイル名を指定すると名前ごと無視され、
拡張子の無い `download` というファイルになってしまうためです
（`.csv` が確実に残るようにしています）。

## 対応ファイル形式

`.xlsx` `.xlsm` `.xlsb` `.xls`（旧形式）`.csv`

SAP GUI から出力した「拡張子は .xls だが中身は別形式」のファイルにも対応しています。

## 開発者向け

### 構成

```
棚卸照合ツール.html      成果物（単一 HTML。利用者はこれだけあればよい）
src/
  index.html            画面の構造
  style.css             デザイン
  reconcile.js          照合ロジック（DOM 非依存の純粋なロジック）
  app.js                画面の制御
vendor/xlsx.full.min.js SheetJS（Excel 読み込み）
tools/
  build.py              src + vendor → 単一 HTML を生成
  make_samples.py       動作確認用のサンプル Excel を生成
tests/
  reconcile.test.mjs    照合ロジックの単体テスト
  e2e.mjs               実際のブラウザで成果物を通しで検証
```

`src/` を編集したら、必ずビルドし直してください。

```bash
python3 tools/build.py
```

### テスト

```bash
# 照合ロジックの単体テスト（Node のみ）
node --test tests/reconcile.test.mjs

# 通し検証（Playwright + Chromium が必要）
pip install openpyxl
python3 tools/make_samples.py     # samples/ にサンプル Excel を生成
python3 tools/build.py
node tests/e2e.mjs                # スクリーンショットも tests/ に出力
```

### ライブラリについて

Excel の読み込みに [SheetJS (xlsx)](https://sheetjs.com/) 0.18.5 を使用しています
（Apache License 2.0、`vendor/LICENSE.sheetjs.txt`）。
オフラインで動かすためにファイル内に埋め込んでいます。

このバージョンには細工された Excel ファイルを開いた場合の既知の脆弱性
（CVE-2023-30533）があります。本ツールは**手元の PC で自社のファイルだけを扱う**
前提のため実用上の問題はありませんが、出所の分からない Excel は開かないでください。
（0.18.5 は npm で配布されている最終版です。以降のバージョンは SheetJS 独自の
配布元でのみ提供されています。）
