# Power Query（M）版 棚卸照合

`棚卸照合ツール.html` と**同じ照合ロジック**を Excel の Power Query で実装したものです。
HTML 版が使えない場合や、Excel 内で完結させたい場合の代替として用意しています。

> **どちらを使うべきか**
> - 配って誰でも使えるようにしたい → **HTML 版**（`棚卸照合ツール.html`）
> - Excel の中で完結させたい／結果を他のシートで加工したい → **こちらの Power Query 版**

---

## 導入手順

### 1. 新規ブックを作り、クエリを1つずつ作る

Excel で **［データ］→［データの取得］→［その他のデータソースから］→［空のクエリ］**
を選び、**［詳細エディター］** を開いて、このフォルダの `.m` ファイルの中身を
**丸ごと貼り付け**ます。

貼り付けたら、左上のクエリ名を**ファイル名と同じ名前**に変更してください。
クエリ同士が名前で参照し合っているため、**名前が違うと動きません**。

### 2. 作る順番

依存関係があるので、この順に作ってください。

| # | クエリ名 | 種類 | 読み込み |
|---|---|---|---|
| 1 | `P_設定` | パラメータ（レコード） | 接続専用 |
| 2 | `fn_文字列` | 関数 | 接続専用 |
| 3 | `fn_数量` | 関数 | 接続専用 |
| 4 | `fn_読込` | 関数 | 接続専用 |
| 5 | `q_マッピング表` | テーブル | 接続専用 |
| 6 | `q_預り書_明細` | テーブル | 接続専用 |
| 7 | `q_預り書` | テーブル | 接続専用 |
| 8 | `q_預り書_倉庫リスト` | **リスト** | 接続専用 |
| 9 | `q_SAP` | テーブル | 接続専用 |
| 10 | **`q_照合結果`** | テーブル | **シートに読み込む** |
| 11 | `q_出力対象外` | テーブル | シートに読み込む |
| 12 | `q_確認事項_数量` | テーブル | シートに読み込む |

「接続専用」は、［閉じて次に読み込む］→［接続の作成のみ］を選びます。
シートを無駄に増やさないためです。

### 3. ファイルパスを設定する

`P_設定` クエリを開き、3つのパスを実際のファイルの場所に書き換えます。
**運用で書き換えるのはこのクエリだけ**です。

```m
預り書パス     = "C:\棚卸\預り書.xlsx",
SAPパス        = "C:\棚卸\SAP在庫残.xlsx",
マッピングパス = "C:\棚卸\マッピング表(倉庫名⇔保管場所名).xlsx",
```

データ開始行が違う場合は `預り書開始行` などの数値も変更してください（1行目がヘッダなら `2`）。

### 4. 実行する

［データ］→［すべて更新］。`q_照合結果` のシートに結果が出ます。

CSV が必要なら、そのシートを［名前を付けて保存］→ **「CSV UTF-8 (コンマ区切り)」** で保存します。

## クエリの役割

| クエリ | 役割 |
|---|---|
| `P_設定` | ファイルパスと読み込み設定。**運用で触るのはここだけ** |
| `fn_文字列` | 突合キー用の文字列化（Trim も全角半角統一もしない＝完全一致） |
| `fn_数量` | 数量パーサ。`1,234` / 全角 / `(123)` / `△123` / `123-` を解釈 |
| `fn_読込` | Excel から指定した**列位置**のデータを取り出す |
| `q_マッピング表` | 保管場所名 → 倉庫名 の辞書（重複は後勝ち） |
| `q_預り書_明細` | 預り書の明細（集計前）。下の2つが参照する中間クエリ |
| `q_預り書` | 預り書を 倉庫名 × 型式 で集計 |
| `q_預り書_倉庫リスト` | 預り書に存在する倉庫名の一覧（出力対象の絞り込み用） |
| `q_SAP` | SAP を変換 → 倉庫名 × 型式 で集計 |
| `q_照合結果` | **メインの出力**。フルアウタージョイン＋判定 |
| `q_出力対象外` | 預り書に無い倉庫のため除外したものの一覧 |
| `q_確認事項_数量` | 数値として解釈できなかったセルの一覧 |

## 照合ロジック（HTML 版と同一）

1. マッピング表で SAP の保管場所名を倉庫名に読み替える。
   **表に無い保管場所名は元の名前をそのまま使う。**
2. 同じ 倉庫 × 型式 の明細を合計する（サマる）。
3. **出力対象を預り書に存在する倉庫だけに絞る。**
   除外したものは `q_出力対象外` で確認できる。
4. フルアウタージョインして判定を付ける。

### 判定区分

| 判定 | 意味 |
|---|---|
| 預り書のみ | 預り書にあるが SAP に無い（SAP への登録漏れの疑い） |
| SAPのみ | SAP にあるが預り書に無い（現物の紛失・計上漏れの疑い） |
| 差異 | 両方にあるが数量が違う |
| 一致 | 両方にあり数量も同じ |

並び順は上の表のとおり（差異が上）。同じ判定の中では 倉庫名 → 型式 の昇順。

### 出力される列

| 判定 | 倉庫名 | 型式 | 預り書台数 | SAP基本数量 | 差異(預り書-SAP) | 預り書明細件数 | SAP明細件数 | SAP保管場所名(変換前) |
|---|---|---|---|---|---|---|---|---|

## HTML 版との違い（把握しておくこと）

| 項目 | HTML 版 | Power Query 版 |
|---|---|---|
| 画面 | アップロード画面・プレビュー・フィルタ・検索あり | **なし**。パスを設定して［すべて更新］ |
| 配布 | HTML 1個を配るだけ | ブックを配る。**各PCでパスの書き換えが必要** |
| ファイル指定 | ドラッグ＆ドロップ | `P_設定` にパスを直書き |
| 列ずれの確認 | 実行前にプレビューで目視 | クエリエディタで確認 |
| CSV 出力 | ボタンで保存（BOM付き UTF-8） | シートから［名前を付けて保存］ |
| 対応形式 | `.xlsx` `.xls` `.csv`、SAP の MHTML 偽装 `.xls` も可 | **`Excel.Workbook` は MHTML 偽装 `.xls` を読めない**ことがある |
| 表記ゆれの検出 | 「惜しいキー」を参考表示 | **未実装** |

### MHTML 偽装ファイルへの対処

SAP GUI からの出力が「拡張子は `.xls` だが中身は MHTML」の場合、Power Query では
読み込みに失敗します。その場合は **Excel で開いて `.xlsx` として保存し直してから**
このクエリに掛けてください（HTML 版はそのまま読めます）。

## 実装上の注意

- **`Table.Join` はキー列名が衝突するとエラーになる**ため、`q_照合結果` では
  SAP 側のキー列を `倉庫名_S` / `型式_S` に改名してから結合しています。
- **マッピングの適用は `Table.NestedJoin`** を使っています。
  1行ずつ `Table.SelectRows` で辞書を引く書き方は数千行で極端に遅くなるためです。
- **大文字小文字の扱い**: M のテキスト比較は基本的に大小文字を区別しますが、
  `Table.Join` は条件によって挙動が変わることがあります。「完全一致」が要件なので、
  初回は実データで一度検証してください。
- `fn_数量` の `Number.FromText` は **`en-US` 固定**にしています。
  PC のロケール設定によって小数点の解釈が変わるのを防ぐためです。
